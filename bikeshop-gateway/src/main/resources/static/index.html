    Como funciona

    O browser só fala com a bikeshop-gateway (9080). Ela encontra cada serviço no bikeshop-registo (Eureka) pelo nome e encaminha o pedido. Cada serviço tem a sua base de dados PostgreSQL. A encomenda não chama o stock nem os pagamentos diretamente: envia mensagens pelo RabbitMQ (exchange bikeshop.eventos) e avança quando chegam as respostas. É a SAGA orquestrada.
